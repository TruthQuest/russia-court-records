# Reporting misuse or a security problem

This code exists to support human rights work. If you see it, or anything made with it, used to identify, locate, surveil, harass or prosecute a defendant, a witness, a lawyer, a journalist, a human rights defender or their families, please tell us.

**Email:** ebrattin@traceoriginresearch.com

Please include, if you can:

- where you saw the code or its output (a link, a repository, a document);
- what it was being used for;
- anything that shows who is using it.

You do not need to give your name. We will not share your report or your identity without your consent.

Use against people is a permanent breach of the [licence](LICENSE.md) (section 4). Trace Origin LLC will act on credible reports, including by requesting that GitHub or other hosts take down misusing copies.

The same address is for security problems in the code itself, for example a way the privacy check could be bypassed or a step that could write personal data where it should not. Please do not open a public issue for either kind of report.
